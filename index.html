6.1 页面布局流程

从「一张空白页面」到「完整页面结构」的基本链路
The complete pipeline from a blank page to a structured web layout

你的原案例

Your Original Case

一个常见网页可以拆成 Header、Navigation、Sidebar、Main Content 和 Footer。页面布局的第一步不是写 CSS，而是先判断这些区域之间是什么结构关系。

A common web page can be divided into Header, Navigation, Sidebar, Main Content, and Footer. The first step is not writing CSS, but identifying the structural relationship among these regions.

嵌入理论：页面布局的四层思路

Embedded Theory: Four Layers of Web Layout
层级解决的问题常用方法
结构 Structure页面有哪些区域？header / nav / main / aside / footer
尺寸 Size每个区域占多大？width / height / max-width / min-height
排列 Arrangement区域之间怎么排？Flex / Grid
适配 Responsive不同屏幕怎么变化？media query / flexible units
核心教学要点： 页面布局是一条连续链路：先划分结构，再确定尺寸，然后排列元素，最后处理不同设备的适配。

关键代码 ① HTML 语义结构

Key Code — Semantic HTML Structure
⭐ <header>Header</header>
<nav>Navigation</nav>
<main class="layout">
  <aside>Sidebar</aside>
  <section>Main Content</section>
</main>
<footer>Footer</footer>

关键点解释：语义标签先表达“页面是什么”，CSS 再决定“页面长什么样”。结构和视觉样式分开，后续修改布局会更简单。

6.2 盒模型与空间关系

把「一个元素」理解成「一个占据空间的盒子」
Understanding every element as a box that occupies space

📌 本节在流程中的位置：元素尺寸（Element Size）

上一节先把页面拆成不同区域。本节解决第二个问题：每个区域到底占多大空间？CSS 盒模型把每个元素拆成 Content、Padding、Border、Margin 四层。

理论核心：CSS Box Model

Theory Core: CSS Box Model
content
部分作用
Content真正放文字、图片或组件的区域
Padding内容与边框之间的内边距
Border元素的边界
Margin元素与其他元素之间的外部距离
教学要点：如果不理解盒模型，就很容易出现“明明设置 width: 300px，元素却比 300px 更宽”的问题。

关键代码 ① border-box

Key Code — border-box
⭐ * {
  box-sizing: border-box;
}

.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #cbd5e1;
  margin: 16px;
}

关键点解释：border-box 会把 padding 和 border 计算在 width / height 内部，实际开发时更容易精确控制尺寸。

6.3 Flex 弹性布局

一维页面布局：解决「一排元素怎么摆」
One-dimensional layout: deciding how items should be arranged along an axis

📌 本节在流程中的位置：布局排列（Arrangement）

当元素大小确定后，就要解决多个元素之间如何排列。Flex 适合一维布局，即主要沿一个方向组织元素：横向或纵向。

理论核心：主轴与交叉轴

Theory Core: Main Axis and Cross Axis
属性解决的问题
flex-direction主轴是横向还是纵向
justify-content元素沿主轴如何分布
align-items元素沿交叉轴如何对齐
gap元素之间的统一间距
flex子元素如何分配剩余空间
教学要点：Flex 的关键不是背属性，而是先判断主轴方向。主轴一旦确定，justify-content 和 align-items 的含义就清楚了。

关键代码 ① Flex 容器

Key Code — Flex Container
⭐ .container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

.sidebar { width: 220px; }
.main { flex: 1; }

关键点解释：flex: 1 常用于“固定侧栏 + 自适应主体”的布局：侧栏保持固定宽度，主体自动吃掉剩余空间。

6.4 Grid 与响应式布局

    
二维网格 + 多设备适配：从「桌面页面」到「响应式页面」

    
Two-dimensional grids + multi-device adaptation: from desktop to responsive layouts


    

      
      
      
    


    

      

        
📌 本节在流程中的位置：二维结构 + 响应适配

        
Grid 适合同时处理“行”和“列”，例如仪表盘、图表矩阵、卡片墙。完成桌面布局后，再用媒体查询根据屏幕宽度调整列数，就形成响应式布局。

      

      

        
嵌入理论：Flex 与 Grid 如何选择？
Embedded Theory: Choosing Between Flex and Grid

        

          
场景推荐原因

          
导航栏 / 一排按钮Flex主要控制一个方向

          
侧栏 + 主体Flex / Grid两者都能自然完成

          
卡片矩阵 / DashboardGrid同时需要行与列

          
手机适配Media Query根据宽度重排布局

        

        
教学要点：Flex 和 Grid 不是竞争关系。实际页面往往是 Grid 管“大结构”，Flex 管“小组件”。

      

    


    

      

        
关键代码 ① Grid + Media Query
Key Code — Grid + Media Query


⭐ .dashboard {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

⭐ @media (max-width: 768px) {
  .dashboard {
    grid-template-columns: 1fr;
  }
}

        
关键点解释：1fr 表示一份可用空间；repeat(3, 1fr) 就是平均分成三列。媒体查询在窄屏时把三列改成一列。
